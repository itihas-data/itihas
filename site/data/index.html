Data

Everything in the database can be downloaded here as plain CSV files, with a codebook that defines every column. Figures taken from the Reserve Bank of India’s Handbook are kept separately because they carry different terms of use. Please cite the database if you use it.

How to cite

If you use the data, cite the database. If you refer to the findings, cite the paper. If you do both, cite both.

The paper

        

        
The database is deposited on Zenodo, which gives each release its own DOI, so cite the version you used. The paper is a working paper for now. If a journal publishes it, the journal reference will replace the one above; the database citation will not change.
