Money

State GDP enters two fiscal rules. The Finance Commission uses it to measure how far each state’s income per person is from that of the highest-income states, which helps to set each state’s share of central taxes. The central government uses it to set how much each state may borrow. Both rules are applied to figures that are later revised. This page shows what the revised figures would have meant. It is about the timing of data, not about whether either rule is fair.
